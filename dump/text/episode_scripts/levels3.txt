Secret Hint 3-1-1:

BONUS ROUND
There are two sections where a solid row of ships move
down and wait.  The first purple ship that comes down
each time has a power-up.  Others carry gems.
#
Secret Hint 3-1-2:

CAMANIS
In the section where enemies fly straight up behind you,
there is a slow-moving enemy that has a power-up.
#
Secret Hint 3-1-3:

SECRET LEVEL : SAWBLADES
The spiders, while hard to reach, contain 10000 pts in
gems.
#
Secret Hint 3-2-1:

?SECRET LEVELS?
Two secret levels in Episode 3 are in the same place.
(Mull that one over.)
#
Secret Hint 3-2-2:

STARGATE
Two of the flying spikes can be destroyed.  Each is
worth 10000 pts.
#
Secret Hint 3-2-3:

EPISODE 3
Play at the hard difficulty level for an extra reward.
#
Secret Hint 3-3-1:

EPISODE 3
There are three secret levels you can access with the
warp bubbles.
#
Secret Hint 3-3-2:

GOD MODE
Type a capital G, then type a SHIFT-RIGHT BRACKET.
#
Secret Hint 3-3-3:

INSANE DETAIL
In the Setup program, type a W when you have detail
level selected.
