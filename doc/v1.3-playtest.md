# v1.3 online play-test script (two humans, two machines)

The automated wire suite covers protocol correctness under injected faults. This script covers
what only humans can judge: feel, readability, and the flows a scripted peer cannot navigate.
Run it on two machines over a real LAN or WAN link, one session per section. Note the build
commit before starting; both machines must run the same build.

Expected throughout every session:

- No "Resyncing players" notice unless a step says to expect one.
- No stalls longer than a second at outposts or level starts.
- The net log (`log/`) ends each session with a NETWORK SESSION START and no desync report.

## 1. Lobby and session setup

1. Host an Online Campaign from the lobby; joiner connects by address. Both see the same
   settings list on the joiner's summary screen (episode, difficulty, credit, speed, netcode).
2. Cancel a connect wait once from each side (Esc while "Waiting for a player" and while
   "Connecting"). The other machine returns to its menu promptly instead of sitting out a
   timeout.
3. Version check: if an older build is available, let it try to join. Both machines should
   report the version mismatch and return cleanly.

## 2. Online Campaign

1. Outpost save: both reach the outpost, one opens Options and saves into a numbered slot.
   The save completes and both loadouts are intact afterwards.
2. Save with the partner gone: start a save, then kill the partner's process. The save
   completes within about six seconds instead of hanging.
3. Save while the partner quits cleanly: the partner uses the in-game quit mid-save. You get
   the "other player quit" path, not a wait.
4. Debug menu across the wire: host edits difficulty and a cheat at the outpost, closes.
   Joiner holds the same values. Repeat from the joiner.
5. Debug menu during an outpost save: joiner edits while the host saves; the edit lands on
   both machines.
6. Custom weapons: each player authors a distinct custom weapon, equips it, and both fly a
   level. Both machines render both designs; no desync.
7. Shop between levels: buy different items on both machines at once, then leave. Both fly
   the level the host picked.
8. Episode transition: finish an episode. Both machines run the outro text and arrive in the
   next episode's first shop together.
9. In-game menu: one player opens the menu mid-level, waits ten seconds, closes. The other
   sees "Other player in options menu." and play resumes cleanly. Then both press Esc at the
   same moment, several tries: exactly one menu opens (the host's), the other machine waits,
   and play resumes with no hitch afterwards.

## 3. Online Endless

1. Double Pickups end to end: host arms Individual credit plus Double Pickups in the lobby.
   Fly at least five zones. Pickup cash visibly doubles for the collector only, and the whole
   session shows zero "Resyncing players" notices.
2. Topsy Turvy online: buy or chart a Topsy Turvy course. The screen and controls flip on
   BOTH machines for that zone and unflip after it.
3. Elite bounty: fly an Apex or Elite Pack course. The bounty toast ("+150 Elite" style)
   appears and the wallet increase sticks; it must not snap back seconds later.
4. Zone tally: after every clear, the level-end screen shows bank interest and the zone bonus
   for BOTH ships, and the partner's wallet matches on both machines at the next outpost.
5. Course rendezvous: with the chooser on Host, the joiner waits at "Partner is charting a
   course."; Esc from that wait returns to the outpost and the session survives. Re-enter and
   let the host chart; both fly the same sector.
6. Withdrawal: commit to leaving, then Esc back out while the partner is still shopping. The
   partner is not dragged out; charting again later works.
7. Downed partner: let one ship die mid-zone in Standard. The survivor finishes the zone, and
   the downed ship revives at the outpost with hull full, shield empty, gear intact.
8. Both down in Relaxed: the host picks each of the three death-menu choices across three
   deaths (Restart Zone, Return to Outpost, End Run). The joiner follows the same branch each
   time without input.
9. Disconnect save: in Relaxed or Standard, the partner closes the game mid-zone. The
   survivor gets the connection-lost screen with Save Game / Don't Save; saving and resuming
   that slot later restores the run at the last outpost.
10. Hardcore: in a Hardcore session, confirm the options menu shows Save and Load darkened,
    Alt+S does nothing, and no disconnect-save prompt is offered when the partner leaves.

## 4. Online Arcade

1. Linked pair: dock the two ships (fly together), steer the turret with player 2, unlink by
   firing a sidekick from player 1. The link sound and marker match on both machines.
2. Orb drops: with Random Pickups on in the host's setup, weapon balls reroll identically on
   both machines (grab a few and compare what they granted).
3. One level with sidekicks on both ships, at least one ammo-limited and one charge-up kick;
   the HUD ammo and charge gauges track on both machines.

## 5. Fault tolerance (optional, needs a throttling tool)

1. Add 150 ms of latency mid-level (clumsy, tc netem, or similar). Play continues; expect
   rollback smoothing, no disconnect.
2. Cut the link entirely for 8 seconds, then restore. The session rides it out; a cut past
   about 16 seconds ends it with "Network connection was lost." and the disconnect-save offer
   where applicable.

Record for every failure: which machine, what was on each screen, and both `log/` net logs.
Pair the `rollback frame N` blocks when reporting a desync.
